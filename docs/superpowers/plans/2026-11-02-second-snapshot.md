# Второй срез пересдач: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Добавить проверяемый второй срез и сравнение с 23.10.2026, сохранив шифрование персональных данных.

**Architecture:** Сохранить статический HTML и исходный шифротекст. Добавить отдельный зашифрованный контейнер второго среза, чистую модель сравнения и воспроизводимый импорт Excel; переключатель управляет всеми существующими вкладками.

**Tech Stack:** HTML/CSS, JavaScript, D3 7.8.5, Python, openpyxl, cryptography, Node test runner, unittest, Playwright. Stageshow используется как визуальный ориентир для рабочего интерфейса, без фиктивных данных в продукте.

## Источники и критерии

- Новая ведомость: 129 студентов, 549 долгов. Реестр причин: 137 студентов, 590 долгов; количественные данные из него не подменяют новую ведомость.
- В новой ведомости 30 записей с приказом о переводе, 168 долгов. Из них 14 приказов от осени 2026 года, 114 долгов. Исключение последних воспроизводит 115/435 из записки; обозначить критерий явно.
- Дата 03.11.2026 взята из записки и находится после даты подготовки 02.11.2026. Не изображать её как уже наступившее состояние.
- Строгое сопоставление по нормализованным ФИО и группе; нечёткое сопоставление не применять автоматически. Несопоставленные записи отмечать.
- Удалённая из ведомости запись не означает подтверждённое закрытие. Сравнивать состав долгов по студенту, дисциплине, форме контроля и семестру.
- Нули и пустые ячейки связи не означают «не выходит на связь». Сохранять исходные заметки внутри шифрованного контейнера.
