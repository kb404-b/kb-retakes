# Публикация и сохранение версий

GitHub Pages настроен на ветку `main`, каталог `/`.
Основной адрес: https://kb404-b.github.io/kb-retakes/.

## Предыдущая опубликованная версия

До релиза двух срезов опубликован коммит
`a52a52e3a3cb6a6d7439799f2dbfb48c4aa8f120` от 26.10.2026.
Он содержит один срез ведомости на 23.10.2026: 137 студентов, 590 долгов.

Сохранены три независимые формы доступа:

- [Рабочая старая страница](https://kb404-b.github.io/kb-retakes/archive/2026-11-02-v1/).
- [ZIP исходного сайта](https://kb404-b.github.io/kb-retakes/archive/2026-11-02-v1/original-site.zip).
- Git-тег `archive-v1-2026-11-02`, указывающий на исходный коммит.

`archive/2026-11-02-v1/index.html`, `.nojekyll` и `robots.txt` совпадают с исходным
коммитом побайтно. `manifest.json` хранит SHA-256. Исходный HTML в архиве не
изменялся: стили и данные остались в первоначальном виде. Ключ доступа прежний;
сам ключ в архив не включён. Данные там по-прежнему зашифрованы.

Архивная папка не является временным файлом. Не удалять и не перезаписывать
её при будущих публикациях. Для следующей старой версии создавать новую папку и тег.

## Выпуск

Перед отправкой проверить тесты, синтаксис, отсутствие секретов, состав Git и
соответствие архивных файлов сохранённому коммиту. Сначала отправить архивный
тег, затем обновить `main` обычным fast-forward push без force.
Дождаться успешного `pages build and deployment` именно для нового коммита.
После сборки проверить основной и архивный адреса, вход, счётчики и блокировку.
Успешный push сам по себе не является подтверждением публикации.

Аккаунт публикации — `S17-lab`; право записи в `kb404-b/kb-retakes` проверено.
CLI-авторизация работает при доступной сети. Ошибка `gh auth status` внутри
сетевой песочницы не доказывает недействительность токена: проверить сетевой
режим перед изменением учётных данных.

## Откат интерфейса без потери архива

Для временного возвращения первой версии восстановить только корневые файлы
из сохранённого тега, создать новый коммит и отправить его в `main`:

```sh
git restore --source=archive-v1-2026-11-02 -- index.html .nojekyll robots.txt
git add index.html .nojekyll robots.txt
git commit -m "revert: restore original retakes dashboard"
git push origin HEAD:main
```

Новые ресурсы и папка архива сохранятся; история не переписывается.
После отката повторно дождаться Pages и проверить опубликованный сайт.
