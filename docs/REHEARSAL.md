# Визуальная и функциональная проверка

02.11.2026, локальная версия в Chromium.

Gold: Stageshow `examples/static-card`, скопирован в игнорируемую `.local/stageshow`.
Эталон снят `film.mjs --still --gate` на 1280/390 px. Оба запуска завершились
`rehearsal passed`, с диагностикой асимметрии отступов самого эталона.
Результат относится к эталону, а не к автоматической оценке рабочего сайта.

Использованы принципы: один главный результат, спокойные вторичные значения,
единые отступы, читаемые строки и отдельная телефонная композиция.
Рабочий интерфейс сохраняет реальные данные и управление. React/kit в сайт
не добавлены: статическое приложение не требует сборщика.

## Функциональная проверка

- Две даты 137/590 и 129/549, все шесть вкладок, 86 вариантов фильтров.
- Без осенних переводов 115/435; приказы любого года 30/168.
- 22 изменившиеся записи из объединения 138: 9 отсутствуют, 12 уменьшились, 1 новая.
  Раскрытие показывает состав разницы.
- Поиск без совпадений, сброс, сортировка долгов в обе стороны, неизвестная связь
  (78 строк), предупреждение о несопоставленной записи.
- Пустой срез 0/0 с явным пустым графиком; восстановление 129/549.
- Ошибочный ключ отклоняется, повторный вход возвращает второй срез.
- После блокировки ключ удалён, API наборов пуст, таблицы очищены, ни одного
  полного ФИО из наборов не осталось в DOM приложения.
- Клавиатура вкладок, reduced motion, Fira Sans 400/500/600.
- Тёмная тема использует официальную белую версию логотипа без перекрашивания.
- Финальный браузерный прогон не зафиксировал ошибок JavaScript.

## Кадры и ограничения

Ширины 320/390/768/1024/1440: документ помещается в окно.
Все вкладки дополнительно проверены на 320/390/1440. В мобильной динамике
числа «было / стало / изменение» помещаются без горизонтальной прокрутки,
статус находится под ФИО. Длинные ведомости прокручиваются внутри таблиц.
Просмотрены обзор, динамика, сравнение в светлой/тёмной теме, узкие состояния.
Контрольные кадры — в `output/playwright/`, ФИО закрыты. Главная карточка
сравнения содержит только агрегаты и пригодна для показа.

Прошли 8 JS- и 9 Python-тестов, синтаксис JS, проверки ресурсов и исходного
шифротекста. В проверенных текстовых ресурсах сайта, импортёре и тестах
не обнаружены действующий ключ и полные ФИО реальных студентов.
Новый набор зашифрован PBKDF2-SHA256 / AES-GCM с новыми случайными salt/iv.

Не проверены Safari/Firefox, полный аудит экранным диктором, первичные учебные
статусы, принятие дат пользователем и живой деплой. Технические проверки
не означают приёмку данных или публикацию. GitHub предоставляет только чтение.
