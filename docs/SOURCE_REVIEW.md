## Предложения

1. Добавить согласованный стабильный ID студента. Смена группы и написания ФИО
   перестанет создавать ложные пары «исчез / появился». Сначала сверить одну
   текущую новую запись.
2. Дополнить реализованный CLI-импорт экраном предварительной сверки: показать
   дату, расхождения и контрольные суммы до принятия среза; хранить историю версий.
3. Добавить журнал работы деканата: дата контакта, ответственный, подтверждение
   объяснительной, следующий шаг. Не выводить эти факты из свободного текста
   и не менять учебный статус автоматически.

Это предложения, а не готовые функции или обязательства университета.
