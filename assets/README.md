# Ресурсы СПбГУТ

Источник официального комплекта: https://www.sut.ru/university/identity.
Использованы локальные неизменённые исходники из университетского проекта
`assets/spbgut/identity/`, проверенного 10 октября 2026 года.

- `sut-logo.svg` и `sut-logo-white.svg` — официальные версии для светлого и тёмного фона, без перерисовки и перекрашивания.
- `fonts/FiraSans-Regular.ttf`, `FiraSans-Medium.ttf`, `FiraSans-SemiBold.ttf` —
  настоящие начертания из официального архива Fira Sans.
- `fonts/OFL.txt` — оригинальная лицензия из того же архива.

Цветовой акцент интерфейса — `#F7941D`; нейтральная основа — `#F2F2F2`,
`#4D4D4D`, чёрный и белый. Более тёмный оранжевый используется для читаемых
подписей и линий на светлом фоне. Внешние шрифтовые сервисы не используются.
