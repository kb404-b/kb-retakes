## Запуск

Из корня проекта:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8765/`, ввести прежний ключ в форму страницы.
Остановка — `Ctrl+C`. Для сайта npm и сборка не нужны. D3 7.8.5 загружается
из cdnjs; Fira Sans и официальные логотипы поставляются локально.

## Что добавлено

- Переключение даты во всех шести разделах; после входа выбран второй срез.
- Карточка общей разницы и «Динамика» с поиском, типами изменений и составом долгов.
- Раздельные фильтры приказов о переводе любого года и осени 2026.
- Заметки реестра, статус связи и отметка несопоставленной записи.
- Мобильное сравнение без горизонтальной прокрутки основных чисел;
  оформление СПбГУТ, светлая и тёмная темы.

Исчезновение строки не считается подтверждённым закрытием. Нули связи означают
неизвестный статус. Сведения записки о контактах и сравнении с 15.10 показаны
отдельно от расчётов по двум датам дашборда.

Первый шифротекст `window.__ENC` сохранён; второй — `data/snapshot-next.js`.
Оба расшифровываются прежним ключом. Ключ не включён в исходники и архив.
Приложение хранит его в `sessionStorage` той же вкладки. Блокировка удаляет ключ,
сбрасывает наборы страницы, очищает отрисованные персональные записи и поиск.
Это общий ключ данных, а не GitHub PAT или серверная учётная запись.
Реальные документы хранить вне Git или в `data/private/`.

## Повторный импорт второго среза

Зависимости нужны только для импорта и Python-тестов:

```sh
python3 -m venv .local/venv
.local/venv/bin/pip install -r scripts/requirements.txt
.local/venv/bin/python scripts/import_snapshot.py --roster data/private/vedomost.xlsx --registry data/private/reestr.xlsx --memo data/private/zapiska.docx --prepared-on 2026-11-02
```

Пути — примеры размещения входных файлов. Ключ запрашивается скрытым вводом.
`--prepared-on` — фактическая дата подготовки, по умолчанию локальная дата запуска.
Даты второго среза и предыдущей сводки читаются из записки. Ведомость задаёт
количества; реестр дополняет причины и связь. Сопоставление строгое по
нормализованным ФИО и группе. Импорт обновляет второй срез относительно базы
23.10.2026 и пишет только шифротекст.

## Проверки

```sh
node --test tests/model.test.js
.local/venv/bin/python -m unittest discover -s tests -p 'test_*.py'
git diff --check
```

Прошли 8 JavaScript- и 9 Python-тестов. В Chromium проверены обе даты, все
разделы, 86 вариантов фильтров, поиск, сортировка, детали, пустые состояния,
неверный ключ, повторный вход и блокировка. Ширины: 320, 390, 768, 1024, 1440 px.

## Публикация

Нужен доступ на запись в `kb404-b/kb-retakes`. Перед публикацией проверить дату
второго среза и одну несопоставленную запись. Обновлять весь комплект:
`index.html`, `app/`, `data/`, `assets/`, `.nojekyll`, `robots.txt`.
Точные настройки ветки Pages не проверены; push сам по себе не подтверждает деплой.
