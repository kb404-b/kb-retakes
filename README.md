## Локальный запуск

Нужны Python 3, современный браузер и доступ к внешним CDN для D3 и шрифтов.
Установка npm-пакетов и сборка не требуются.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Команду выполнить из корня репозитория, затем открыть
`http://127.0.0.1:8765/` и ввести ключ доступа в форме страницы.
Остановка сервера — `Ctrl+C`.

Ключ не хранится в репозитории. Он расшифровывает данные в браузере и сохраняется
приложением в `sessionStorage` для повторного открытия в той же вкладке.
Кнопка «Заблокировать» удаляет сохранённый ключ и возвращает форму входа.
Это не учётная запись пользователя и не доступ к GitHub.

## Работа в Codex

Открыть эту папку как локальный проект Codex. `AGENTS.md` содержит инструкции,
а `docs/PROJECT_CONTEXT.md` — карту кода и проверенную исходную точку.
Для следующих задач достаточно описать нужное изменение и ожидаемый результат.

Текущая подготовка выполнена в локальной ветке `codex/project-onboarding`.
Исходный `index.html` сохранён без изменений. Публикация этой подготовки не выполнена.

Изменения можно разрабатывать и проверять локально. Для отправки в исходный
репозиторий потребуется GitHub-подключение с правом записи именно в
`kb404-b/kb-retakes`. Ключ страницы для этого не подходит.

## Обновление данных

В репозитории нет исходных Excel/CSV и программы, которая создала зашифрованный
HTML. Для воспроизводимого обновления данных нужно отдельно восстановить импорт
ведомостей, правила сопоставления и шифрование. Существующую страницу можно
развивать уже сейчас; наличие готового конвейера обновления не подтверждено.

Реальные ведомости и расшифрованные выгрузки хранить вне Git или в
`data/private/`. Не добавлять персональные данные и ключи в коммиты.
