# kb-retakes: работа в Codex

Дашборд деканата факультета кибербезопасности СПбГУТ по академическим
задолженностям после пересдачи. Отвечать по-русски, кратко и полными предложениями.

## Контекст и границы

- Начать с `README.md` и `docs/PROJECT_CONTEXT.md`.
- Существующее приложение — статический `index.html`, без сборки, npm и сервера API.
  Не переводить его на другой стек без задачи пользователя.
- Репозиторий публичный. Данные внутри `window.__ENC` зашифрованы; не раскрывать их
  в исходниках, документации, тестовых фикстурах, логах и снимках экрана для публикации.
- Токен страницы — ключ расшифровки, а не GitHub PAT. Не записывать его в файлы,
  Git, URL, отчёты или инструкции. Для проверки вводить только во время сеанса.
- Приватные ведомости и выгрузки хранить вне Git или в игнорируемом `data/private/`.
- Историю Claude восстановить нельзя. Внешние документы пользователя прочитаны
  при добавлении второго среза; их роли и SHA-256 — в `docs/SOURCE_REVIEW.md`.
  Импорт теперь находится в `scripts/import_snapshot.py`.

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8765/`. Расшифровка использует Web Crypto: нужен HTTPS
либо localhost. D3 7.8.5 загружается из cdnjs; шрифты и логотипы хранятся локально.
Сборка сайта не нужна. Тесты: `node --test tests/model.test.js` и
`python -m unittest discover -s tests -p "test_*.py"` с зависимостями
`scripts/requirements.txt`. Окружение описано в README; линтер не настроен.

## Смысл показателей

- `debts`: одна строка — одна задолженность; `students`: сведения о студенте.
- Число студентов и число задолженностей — разные показатели.
- `course` относится к семестру возникновения долга; это не подтверждённый текущий
  курс студента. В исходном срезе `course = ceil(sem / 2)`.
- Идентичность — нормализованные ФИО и группа. Нечёткое сопоставление не применять
  автоматически. Исчезновение записи не означает подтверждённое закрытие.
- Второй срез датирован 03.11.2026 по записке, подготовлен 02.11.2026. Не выдавать
  указанную дату за подтверждение актуального состояния.
- Приказы любого года и осени 2026 — разные фильтры: без них 99/381 и 115/435.
- Нули связи означают неизвестный статус, а не отсутствие контакта.
- «Без объяснительной» в основном KPI исключает принятых переводом.
- `closed` означает отсутствие ответившего на форму в более поздней ведомости.
  Закрытие долгов требует подтверждения; не превращать предположение в факт.
- Дата KPI берётся из выбранного среза. Контейнер второго — `data/snapshot-next.js`;
  исходный `window.__ENC` сохранять. Новые заметки не переносить в историю задним числом.

## Изменения и проверка

- До правки проверить `git status`; сохранять чужие изменения и исходный шифротекст.
- Делать небольшие изменения в отдельной ветке. Перед публикацией показывать
  результат и проверки; учитывать, что обновление ветки Pages может менять боевой сайт.
- Проверять затронутые сценарии в браузере: вход, вкладки, фильтры, поиск, сортировку,
  раскрытие студента, блокировку; для интерфейса также узкий экран и консоль.
- Для расчётов и импорта использовать синтетические данные и содержательные тесты.
  Одной проверки синтаксиса недостаточно для подтверждения работы приложения.
- При проверке реальных данных выводить только агрегаты. В конце заблокировать
  страницу и очистить введённый ключ в тестовом браузере.
- Разделять локальные проверки, проверку опубликованного сайта и публикацию изменений.
  Не утверждать, что push или деплой выполнен, без подтверждения.

## Оформление

Новые университетские материалы оформлять в стиле СПбГУТ: Fira Sans,
оранжевый `#F7941D`, серые `#F2F2F2` и `#4D4D4D`, чёрный и белый.
Официальные ресурсы доступны в родительском проекте `assets/spbgut/identity/`.
Интерфейс использует СПбГУТ и принципы Stageshow. При технических правках
сохранять иерархию; не заменять настоящие данные макетными числами.
